# Coding Agent Guidelines

> **CRITICAL MANDATE**: Before modifying any code or configuration in this repository, **you MUST read and adhere to [`AGENT_RULES.md`](./AGENT_RULES.md)**.

## Workflow Overview
1. **First Step**: Review [`AGENT_RULES.md`](./AGENT_RULES.md) for protected areas and operating rules.
2. **Project Context**: Check [`GEMINI.md`](./GEMINI.md) and [`docs/`](./docs/) for system architecture.
3. **Execution**: Make focused changes without refactoring unrelated features.
4. **Testing**: Run `npm run build` to verify TypeScript and bundling.
5. **Documentation**: Update relevant Markdown docs and walkthroughs.
